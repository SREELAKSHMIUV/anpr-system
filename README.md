# 🚗 ANPR System using YOLOv8

This project implements an Automatic Number Plate Recognition (ANPR) system using a custom-trained YOLOv8 model and Plate Recognizer API.

---

## 🔥 Features

- License plate detection using YOLOv8
- Line-crossing based detection (event-based)
- Avoids duplicate detections
- Saves detected plates with timestamp
- Real-time video processing
